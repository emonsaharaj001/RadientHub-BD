# 🌟 RadientHub-BD

RadientHub-BD is an **online salon pre-booking web application** developed using Java and Spring Boot.

The project was built as a learning-based project while exploring Java backend development, Spring Boot, database integration, and Gradle.

## 📌 Project Overview

RadientHub-BD is designed to provide an online platform where users can explore salon-related services and make pre-bookings online.

The main focus of the project was to learn and practice **Java backend development** and understand how a web application works with a database.

## 🛠️ Technologies Used

### Backend

* Java 21
* Spring Boot
* Spring Web
* Spring Data JPA
* Gradle

### Database

* H2 Database
* JPA / Hibernate

### Frontend

* HTML
* CSS

The main application logic was developed with **Java and Spring Boot**, while HTML and CSS were used for the frontend interface.

## ✨ Key Features

* Online salon pre-booking system
* Service-related booking functionality
* Backend application built with Java
* Database integration
* JPA-based data management
* Web-based user interface
* Gradle-based project configuration
